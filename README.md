
# Actividad 7 - Cristian Cruz

Tema: Herramientas digitales para la gestión comercial y financiera

## Archivos
- `index.html`: blog académico.
- `presentacion.html`: presentación interactiva.
- `styles.css`: estilos compartidos.

## Publicación con GitHub Pages
1. Crea un repositorio nuevo, por ejemplo: `actividad7-cristian-cruz`.
2. Sube los tres archivos al repositorio.
3. En GitHub entra a Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch, rama `main`, carpeta `/root`.
5. Guarda la configuración.
6. La URL tendrá una estructura similar a:
   `https://TU_USUARIO.github.io/actividad7-cristian-cruz/`
7. Comprueba la URL en una ventana privada.

Para la entrega académica usa la URL pública del blog y la URL de `presentacion.html`.
